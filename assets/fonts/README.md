Fonts bundled with the LIFT panel. Both are licensed under the SIL Open Font
License 1.1, which allows bundling and embedding; the licence texts sit next
to the fonts and must ship with any binary that embeds them.

- Jost (OFL-Jost.txt): static 400/500/600/700 instances cut with fontTools
  from Google Fonts' `ofl/jost/Jost[wght].ttf`. The family name is unchanged
  (neither font declares a Reserved Font Name).
- Space Mono (OFL-SpaceMono.txt): `SpaceMono-Regular.ttf` and
  `SpaceMono-Bold.ttf` from Google Fonts, unmodified.
