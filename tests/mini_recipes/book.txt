# LIFT Mini scenario book. lift_mini_session plays each recipe from a fresh
# Mini (a new project: SYNTH screen, LOOM, 100 BPM, track 1, octave 0, 1x
# speed, empty tape, no loop, no clip) and
# checks it. How to read and extend this file: tests/mini_recipes/README.md.
#
# Quick reference
#   button NAME [down|up|tap]      SYNTH DRUM TAPE MIX OCT- OCT+ LIFT DROP REC PLAY SHIFT
#   key SPEC [down|up|tap]         SPEC: 1-24 chromatic from C3, w1-w14 white, b1-b10 black
#   turn COLOUR DETENTS [each]     yellow blue black red; "each" = one detent at a time
#   push COLOUR [down|up|tap]      encoder press
#   midi CH noteon N [VEL] | noteoff N | cc N V     (as the Pico sends it)
#   wait MS | run SECONDS | mark
#   input silence | sine HZ AMP | noise AMP
#   fill track N sine HZ AMP | snapshot NAME | shot NAME | paint | chaos SEED MOVES
#   expect METRIC OP VALUE | expect toast has|lacks TEXT
# A "tap" holds 40 ms (keys: 150 ms). Time only moves with wait, run and taps.

  expect speed == 1
  expect playing == 0
  expect recording == 0
  expect shift == 0
  expect clip == 0
  expect source == INTERNAL

  button DRUM tap
  button DRUM tap

  expect knob blue > 0.599
  expect knob blue < 0.601
  expect loop > 9.59
  expect loop < 9.61

  expect track_rms 2 > 0.1

  expect mode == SYNTH

recipe: SHIFT + turn moves the knob's second parameter, and its release is not a tap
  turn yellow 5          # one fast Pico event: 5 detents x 2 % = +0.1
  expect knob yellow > 0.599
  expect knob yellow < 0.601
  wait 300
  button SHIFT down
  turn yellow 5          # GLIDE, not PITCH (a slow turn: no acceleration)
  button SHIFT up
  expect sknob yellow > 0.599
  expect sknob yellow < 0.601
  expect knob yellow > 0.599
  expect knob yellow < 0.601
  expect shift == 0

recipe: Slow turns move in small steps, fast turns in big ones
  turn blue 10 each 200   # a slow hand: 1 % a detent
  expect knob blue > 0.599
  expect knob blue < 0.601
  turn black 10 each      # a quick hand: 4 % a detent after the first
  expect knob black > 0.85
  turn red 10 each 200
  turn red -10 each 200   # slow both ways lands back where it started
  expect knob red > 0.499
  expect knob red < 0.501

recipe: Releasing SHIFT mid-turn keeps that knob on its second parameter briefly
  button SHIFT down
  turn yellow 1
  button SHIFT up
  wait 50
  turn yellow 1           # within 150 ms of the last detent: still GLIDE
  expect sknob yellow > 0.515
  wait 400
  turn yellow 1           # after it: PITCH
  expect knob yellow > 0.509

recipe: SHIFT + blue on TAPE picks the tape CHARACTER
  button TAPE tap
  button SHIFT down

  button SHIFT up
  wait 20
  expect character == 2
  button SHIFT down
  turn blue 9

  expect character == 3

recipe: SHIFT + red on TAPE sets LOOP LENGTH in bars, and back off
  button TAPE tap
  button SHIFT down

  button SHIFT up
  wait 20
  expect loop > 4.79      # 2 bars at 100 BPM
  expect loop < 4.81
  button SHIFT down
  turn red -5
  button SHIFT up
  wait 20
  expect loop == 0

recipe: MIX knobs set each track's level; SHIFT + turn pans it
  button MIX tap

  wait 20
  expect fader 1 < 0.6
  expect fader 2 > 0.99

  expect pan 1 == 0
